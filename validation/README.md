# Validation cohort

`validation-cohort.csv` is the published n = 14 reference cohort: platforms with directly
comparable, publicly documented annual retention rates (SEC filings, earnings reports, CIRP,
Antenna, industry reports), paired with their current V3.1 B-scores.

Primary result: Spearman rho = 0.79 (p < 0.001). This is a preliminary, descriptive
validation — not causal. Inter-rater reliability (ICC) has not yet been measured; all scores
to date come from a single evaluator. Live version: https://blackholeindex.com/validation

Note: an earlier file in this directory was a synthetic placeholder generated from model
scores for layout testing and was never a real external dataset. It was replaced by this
cohort on 2026-07-20.
